ABOUT ME

Hi, I'm Sana. I Build Apps With Purpose.

I'm a Mobile App Developer who enjoys turning ideas into practical, user-friendly mobile applications. My main focus is Android development, while I also work with Kotlin, Python, Flutter UI development, and AI API integration.

MY STORY

From Learning to Building

My journey started with learning programming fundamentals and understanding how software works behind the scenes.

Over time, my interest moved toward mobile application development. I started building Android applications and working with modern development tools, architectures and APIs.

Today, I enjoy working on applications that solve practical problems, provide useful experiences and have clean, simple interfaces.

Alongside development, I also teach programming and computer science concepts, which has helped me develop a strong habit of explaining technical ideas in a simple way.
