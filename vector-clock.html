THE IDEA

Simple tools. One useful application.

Vector Clock was created as a personal mobile application project focused on everyday time management.

The application brings commonly used time tools together so users can access alarms, timers, and a stopwatch from a single application.

Building the project also provided an opportunity to work through the complete mobile application lifecycle — from development and testing to publishing and maintaining the application.
