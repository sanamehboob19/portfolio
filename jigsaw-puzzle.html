THE IDEA

A simple idea. An interactive experience.

Jigsaw Puzzle is a personal Android game project created to explore interactive gameplay and application development beyond utility apps.

The project focuses on presenting a familiar puzzle concept through a straightforward mobile experience that is easy to understand and enjoyable to use.

Building a game also provided an opportunity to work with interaction, user input, visual elements, application flow, and testing across supported devices.
